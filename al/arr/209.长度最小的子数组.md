# 长度最小的子数组 手写题（滑动窗口经典题）
这是前端面试**数组算法方向高频题**，字节、阿里等大厂常考，核心考察**滑动窗口（双指针）思想**、**数组问题的优化思维**，属于必须掌握的滑动窗口入门题。

---

## 一、题目描述
给定一个含有 `n` 个正整数的数组和一个正整数 `s`，找出该数组中满足其和 `≥ s` 的长度最小的**连续子数组**，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

```js
// 示例
输入：s = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是满足条件的长度最小的连续子数组。
```

### 关键前提
数组元素**全部为正整数**——这是滑动窗口解法成立的核心条件。

---

## 二、最优解：滑动窗口（双指针）
### 核心思路
利用「数组元素全为正」的特性，维护一个**可变大小的滑动窗口**：
1. 右指针 `right` 向右扩张窗口，将元素加入窗口和
2. 当窗口内的和 `≥ s` 时，尝试**向左收缩左指针**，缩小窗口长度，同时更新最小长度
3. 直到窗口和 `< s` 时，停止收缩，继续扩张右指针

因为元素全为正，窗口扩大则和递增，窗口缩小则和递减，保证了滑动窗口的单调性，不会漏掉最优解。

### 满分代码实现
```js
/**
 * @param {number} s 目标和
 * @param {number[]} nums 正整数数组
 * @return {number} 满足条件的最短连续子数组长度
 */
var minSubArrayLen = function(s, nums) {
  const n = nums.length;
  let left = 0; // 窗口左边界
  let sum = 0;  // 窗口内元素和
  let minLen = Infinity; // 记录最小长度，初始化为无穷大

  // 右指针遍历，扩张窗口
  for (let right = 0; right < n; right++) {
    sum += nums[right];

    // 当窗口和满足条件时，尝试收缩左边界，寻找更短的子数组
    while (sum >= s) {
      // 更新最小长度
      minLen = Math.min(minLen, right - left + 1);
      // 左指针右移，缩小窗口
      sum -= nums[left];
      left++;
    }
  }

  // 如果minLen还是无穷大，说明没有符合条件的子数组，返回0
  return minLen === Infinity ? 0 : minLen;
};
```

### 步骤推演（以示例 `s=7, nums=[2,3,1,2,4,3]` 为例）
| right | 加入元素 | sum | sum≥7？ | 收缩左指针 | 最小长度 |
|-------|----------|-----|---------|------------|----------|
| 0     | 2        | 2   | ❌      | 不收缩     | Infinity |
| 1     | 3        | 5   | ❌      | 不收缩     | Infinity |
| 2     | 1        | 6   | ❌      | 不收缩     | Infinity |
| 3     | 2        | 8   | ✅      | 减去nums[0]=2，sum=6，left=1 | 4 |
| 4     | 4        | 10  | ✅      | 减去nums[1]=3，sum=7，left=2 → 再减nums[2]=1，sum=6，left=3 | 2 |
| 5     | 3        | 9   | ✅      | 减去nums[3]=2，sum=7，left=4 → 再减nums[4]=4，sum=3，left=5 | 2 |

最终最小长度为 2，符合预期。

### 复杂度分析
- **时间复杂度**：O(n)
  每个元素最多被右指针访问一次、被左指针访问一次，总共2n次操作，线性时间。
- **空间复杂度**：O(1)
  仅使用常数个变量，原地操作。

## 三、进阶思路：前缀和 + 二分查找（面试加分项）
### 适用场景
当面试官追问「如果不能用滑动窗口，还有什么优化方法」时，可以讲这个方案；同时该方法也适用于「子数组和固定值」类问题的扩展。

### 核心思路
1. 先计算前缀和数组 `prefix`，其中 `prefix[i]` 表示前 `i` 个元素的和（`prefix[0]=0`）
2. 因为数组元素全为正，**前缀和是严格递增的有序数组**
3. 枚举每个子数组的起点 `i`，在前缀和中**二分查找**最小的 `j`，使得 `prefix[j] - prefix[i] ≥ s`
4. `j - i` 就是以 `i` 为起点的最短子数组长度，更新全局最小值

### 代码实现
```js
var minSubArrayLen = function(s, nums) {
  const n = nums.length;
  const prefix = new Array(n + 1).fill(0);
  // 构建前缀和数组
  for (let i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + nums[i];
  }

  let minLen = Infinity;

  // 枚举每个起点i
  for (let i = 0; i < n; i++) {
    const target = prefix[i] + s;
    // 二分查找第一个 >= target 的位置
    let left = i + 1;
    let right = n;
    while (left <= right) {
      const mid = Math.floor((left + right) / 2);
      if (prefix[mid] >= target) {
        right = mid - 1;
      } else {
        left = mid + 1;
      }
    }
    // 找到符合条件的j，更新长度
    if (left <= n) {
      minLen = Math.min(minLen, left - i);
    }
  }

  return minLen === Infinity ? 0 : minLen;
};
```

### 复杂度分析
- **时间复杂度**：O(n log n)
  构建前缀和O(n)，每个起点二分查找O(log n)，总共有n个起点。
- **空间复杂度**：O(n)
  需要额外的前缀和数组。

## 四、基础思路：暴力枚举
### 核心思路
两层循环枚举所有连续子数组的起点和终点，计算子数组和，满足条件则更新最小长度。

### 代码实现
```js
var minSubArrayLen = function(s, nums) {
  const n = nums.length;
  let minLen = Infinity;

  for (let i = 0; i < n; i++) {
    let sum = 0;
    for (let j = i; j < n; j++) {
      sum += nums[j];
      if (sum >= s) {
        minLen = Math.min(minLen, j - i + 1);
        break; // 再往后长度更大，无需继续
      }
    }
  }

  return minLen === Infinity ? 0 : minLen;
};
```

### 复杂度
- 时间：O(n²)，大数据量会超时
- 空间：O(1)

## 六、面试必问延伸问题
### 1. 为什么这道题可以用滑动窗口？如果数组有负数还能用吗？
**答案：**
滑动窗口成立的核心前提是**窗口和的单调性**：窗口扩大和一定增大，窗口缩小和一定减小。
- 数组元素全为正整数时，满足单调性，因此可以用滑动窗口
- 如果数组包含负数，扩大窗口和可能变小，缩小窗口和可能变大，单调性被破坏，**不能直接用滑动窗口**。这种情况可以用前缀和+单调队列来进一步优化。

### 2. 滑动窗口的适用场景有哪些？
**答案：**
滑动窗口一般用于解决**连续子数组/子串**的极值问题，常见场景：
- 子数组和/积满足某条件（和≥目标、积小于目标）
- 子串包含/不包含某些字符（无重复字符的最长子串、最小覆盖子串）
- 核心前提是窗口的扩张和收缩具有单调性

### 3. 这道题的边界情况有哪些？
**答案：**
- 数组为空：返回0
- 单个元素就≥s：返回1
- 整个数组的和都<s：返回0
- 所有元素都等于s：最小长度为1

## 七、面试回答话术
> 这道题我首先会用**滑动窗口**来做，这是最优解，时间复杂度O(n)。
> 
> 因为数组元素都是正整数，窗口和具有单调性。我用左右两个指针维护一个窗口，右指针不断扩张，把元素加入窗口和。当窗口和大于等于目标值时，我就尝试收缩左指针，同时更新最小长度，直到窗口和小于目标值为止。
> 
> 这样每个元素最多被左右指针各访问一次，整体是线性时间。如果不能用滑动窗口的话，还可以用前缀和加二分查找的方案，时间复杂度是O(n log n)。
> 
> 最后要注意边界处理，如果没有符合条件的子数组，要返回0。
