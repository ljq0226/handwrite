## 一、先讲你代码里的隐藏问题
你的代码对方阵（3×3）测试正常，但遇到**单行、单列、长方形矩阵**时，会出现重复添加元素的错误。

### 反例验证
输入单行矩阵：`matrix = [[1,2,3,4]]`（1行4列）
你的代码执行过程：
1. 初始边界：`left=0, right=3, top=0, bottom=0`
2. 左→右遍历顶行：推入 `1,2,3,4`，`top` 变为 1
3. 上→下遍历右列：`i` 从 1 到 0，循环不执行，`right` 变为 2
4. **问题出现**：右→左遍历底行：`i` 从 2 到 0 依然会执行，重复推入 `3,2,1`
5. 最终结果长度远超 4，完全错误

### 根本原因
每完成一条边的遍历后，**没有校验「剩下的行/列是否还有效」**，导致单行/单列场景下，已经没有可遍历的元素了，后续循环依然会执行。

## 二、面试满分标准实现（修复边界bug）
```js
/**
 * @param {number[][]} matrix
 * @return {number[]}
 */
var spiralOrder = function (matrix) {
  // 空矩阵异常处理
  if (matrix.length === 0 || matrix[0].length === 0) return [];

  const m = matrix.length;    // 总行数
  const n = matrix[0].length; // 总列数
  const res = [];

  // 定义四个边界：左、右、上、下
  let left = 0;
  let right = n - 1;
  let top = 0;
  let bottom = m - 1;

  // 循环条件：边界有效（左不超右，上不超下）
  while (left <= right && top <= bottom) {
    // 1. 从左到右，遍历最顶行
    for (let i = left; i <= right; i++) {
      res.push(matrix[top][i]);
    }
    top++; // 顶边界向下收缩

    // 2. 从上到下，遍历最右列（先校验：还有行可遍历）
    if (top <= bottom) {
      for (let i = top; i <= bottom; i++) {
        res.push(matrix[i][right]);
      }
      right--; // 右边界向左收缩
    }

    // 3. 从右到左，遍历最底行（先校验：还有列可遍历）
    if (left <= right) {
      for (let i = right; i >= left; i--) {
        res.push(matrix[bottom][i]);
      }
      bottom--; // 底边界向上收缩
    }

    // 4. 从下到上，遍历最左列（先校验：还有行可遍历）
    if (top <= bottom) {
      for (let i = bottom; i >= top; i--) {
        res.push(matrix[i][left]);
      }
      left++; // 左边界向右收缩
    }
  }

  return res;
};
```

## 三、核心原理逐步骤拆解
### 核心思想：按层模拟 + 边界收缩
把矩阵看成一层一层的「洋葱圈」，每一轮走完最外层的四条边，然后四个边界向内收缩一圈，直到所有层都遍历完成。

顺时针遍历固定四步：
1. **顶行：左 → 右**：遍历最上方一行，从左边界到右边界；走完后顶边下移一格
2. **右列：上 → 下**：遍历最右侧一列，从新的顶边到底边；走完后右边左移一格
3. **底行：右 → 左**：遍历最下方一行，从新的右边到左边；走完后底边上移一格
4. **左列：下 → 上**：遍历最左侧一列，从新的底边到顶边；走完后左边右移一格

### 为什么必须加三次边界判断？
这是面试官的核心扣分点：
- 单行矩阵：走完顶行后 `top > bottom`，右列、底行、左列都不应再执行
- 单列矩阵：走完右列后 `left > right`，底行、左列都不应再执行
- 只有加上判断，才能覆盖所有长方形矩阵的场景

## 四、复杂度分析
- **时间复杂度**：O(m×n)，矩阵中每个元素恰好被访问一次，无重复操作
- **空间复杂度**：O(1)，除结果数组外，仅使用常数个变量

## 五、面试高频延伸变体
### 变体1：螺旋生成矩阵（LeetCode 59，字节常考）
**题目**：给定正整数 `n`，生成一个包含 1 到 n² 所有元素、按顺时针螺旋排列的 n×n 正方形矩阵。

**思路**：和遍历逻辑完全一致，把「取值」换成「赋值」即可。
```js
var generateMatrix = function(n) {
  const res = new Array(n).fill(0).map(() => new Array(n));
  let left = 0, right = n - 1, top = 0, bottom = n - 1;
  let num = 1;

  while (left <= right && top <= bottom) {
    for (let i = left; i <= right; i++) res[top][i] = num++;
    top++;
    for (let i = top; i <= bottom; i++) res[i][right] = num++;
    right--;
    for (let i = right; i >= left; i--) res[bottom][i] = num++;
    bottom--;
    for (let i = bottom; i >= top; i--) res[i][left] = num++;
    left++;
  }
  return res;
};
```

### 变体2：逆时针螺旋遍历
**题目**：按逆时针顺序返回矩阵元素。
**思路**：调整四条边的遍历顺序即可：左列从上到下 → 底行从左到右 → 右列从下到上 → 顶行从右到左，边界收缩逻辑不变。
